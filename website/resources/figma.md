# Figma libraries

<ResourceLinks />

## Primary file

[Studio DS on Figma](https://www.figma.com/design/8wXGfy006ncSwwx6BPrAAh/Studio-DS)

## What to use

| Library | Purpose |
| --- | --- |
| Studio · Semantic | Light/Dark color variables |
| Studio · Typography | Type styles |
| Studio · Primitives | Space, radius, icon, motion |
| Studio/Elevation/* | Elevation effects |
| Studio/* sets | Components to implement in React |

Enable the library in your product files and prefer **variables** over local styles where possible.
