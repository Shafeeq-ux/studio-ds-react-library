## Repository

## Install (library)

```bash
npm install studio-ds
```

> Publishing to the public npm registry is part of the production-graduate roadmap. Until then, install from the GitHub repo or a linked workspace.

## Scripts

| Script | Purpose |
| --- | --- |
| `npm run storybook` | Local Storybook |
| `npm run build` | Library build → `dist/` |
| `npm run build-storybook` | Static Storybook |
| `npm run docs:dev` | VitePress guidelines (this site) |
| `npm run build-site` | Docs + Storybook for GitHub Pages |
