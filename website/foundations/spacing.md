# Spacing & radius

Spacing creates rhythm; radius softens interactive surfaces.

<ResourceLinks />

## Space scale

Common steps (px): **4 · 8 · 16 · 24 · 32 · 40 · 48 · 64** — exposed as CSS variables under `--sds-*` primitives and used via `Stack` `gap`.

```tsx
<Stack gap={16}>...</Stack>
```

## Radius

Primary radii: **6 · 8 · 12**. Prefer tokens over hard-coded `border-radius`.
