# Color

Semantic color creates clear interfaces across Light and Dark.

<ResourceLinks />

## Principles

- Prefer **semantic** roles over hex values.
- Pair text/background tokens for contrast.
- Status colors communicate meaning (error, success, warning).
- AI surfaces use dedicated `--sds-color-ai-*` roles.

## Categories

| Role group | Examples |
| --- | --- |
| Text | primary, secondary, tertiary, reference |
| Background / surface | canvas, default, secondary, hover, disabled |
| Border | default |
| Action | primary, hover, subtle |
| Focus | ring |
| Status | error, success, warning |
| AI | foreground, surface |
| Overlay | tooltip |
