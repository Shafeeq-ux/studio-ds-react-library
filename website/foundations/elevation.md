# Elevation

Elevation adds depth and dimension.

<ResourceLinks />

## Tokens

| Token | Role |
| --- | --- |
| `--sds-elevation-subtle` | Soft lift for cards / resting surfaces |
| `--sds-elevation-popover` | Menus, popovers, floating UI |

Mapped from Figma **Studio/Elevation/***.

## Guidance

- Prefer elevation tokens over ad-hoc `box-shadow`.
- Dark mode elevations must remain visible on canvas backgrounds — verified via Storybook Theme toggle.
